# 背景

新增一路基于用户历史行为的I2I召回，捕捉用户的实时兴趣，进一步补充个性化召回能力

# 目标

提升召回多样性和提升访购率

# 模型结构

采用 GraphSAGE 算法。通过用户同一 session 内的点击的共现关系构建图，贡献次数作为边上的权重。在聚合的时候加权平均。层数选2层。采样10个临近节点。mean 平均聚合，嵌入维度 128，学习率 0.001 ，激活函数 ReLU，epoch 50。

# 调用链路

1.  线上收集用户的历史购买 item 和实时浏览 item
2.  离线存储好这个 item 对应的推荐 item
3.  通过 k-v 读取，得到 i2i 召回
4.  蛇形选取每个 item 召回的 top1 ，拼接得到50个 poi 作为最终的补充召回。

# 评估指标

线上漏斗收益率，平均总共召回 69，平均新增召回 14.7，曝光层新增个数 0.096 个。实验推全订单 +1211 单/天，大盘访购率提升 2bp
