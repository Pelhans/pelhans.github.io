# LaMDA Language Models for Dialog Applications

> 论文链接：[LaMDA: Language Models for Dialog Applications](https://arxiv.org/abs/2201.08239)

特点参数多（137B)，训练数据量大(1.56T words)。

-   模型结构：decoder-only Transformer，类似 GPT。64 层， 维度 8192， ff 维度 65536, 128 个头，k 和 v 的维度是 128 。。。 1024 个 TPU-v3 上要跑 57.7 天
-   数据集：
-   评估：

-   质量：

-   合理性：指模型是否产生在对话上下文中有意义的响应（例如，没有常识错误，没有荒谬的回应，以及与先前的回应没有矛盾）
-   特异性：通过判断系统的响应是否特定于前面的对话上下文来衡量的，而不是适用于大多数上下文的通用回应
-   趣味性：衡量模型是否产生了富有洞察力、出乎意料或机智的回应，因此更有可能创造更好的对话

-   安全：安全度量由一组说明性的安全目标组成，这些目标试图限制模型的输出，以避免任何可能对用户造成伤害的意外结果
-   根基性 Groundedness：幻觉

-   模型训练：用 GSPMD 框架(GSPMD 是一个基于 XLA 编译器的模型分布系统，它允许将 TPU 集群视为单个虚拟设备，并在几个张量上使用 sharding annotations 来指示编译器自动分发数据并在数千个设备上进行计算) 训练模型。自回归任务
-   模型微调：

-   微调数据（总计 58K对话）：众包标注，为了保证质量（评估里的质量），让众包与 LaMDA 实例就任何主题进行交互，共收集6400 个对话，共 121K 轮，每轮对话要持续 14-30 次；和 SSI 类似，通过要求众包工作者与LaMDA实例就任何主题进行交互来收集8K次和48K轮的对话；为了保证安全，收集了 4k个对话和 40 k轮数据（有点迷惑）..很多关键指标还被3个不同的crowdworker标注，并投票决定最终的结果，以保证标注质量
-   微调任务 : 先fine-tune一个预测 SSI 和 safety rating的模型，过滤掉 safety 分数比较低的回复，然后在ranking阶段选最高得分的回复作为最终结果。得分计算方法 3 \* P(sensible) + P(specific) + P(interesting)：

-   生成式微调（<context> <sentinel> <response>)
-   判别式微调 （<context> <sentinel> <response> <attribute-name> <rating>)

-   减轻幻觉的微调：

-   利用外部知识（一个信息检索异同，一个计算器，一个翻译器）

-   Information retrieval： "How old is Rafael Nadal?" -> ["Rafael Nadal / Age / 35"]
-   Calculator: "135+7721" -> ["7856"]
-   Translator: "hello in French" -> ["Bonjour"]

-   将知识融入：两个 task，一个 base 生成任务，一个research (借助上面的三个 tool 做）

-   推理阶段模型输出有两种：

-   User 开头 ： 后面跟着的文本是最终回复
-   TS 开头 ： 后面跟着的事要输入 TS 并以此输出作为下一轮模型的输入，继续改进回复，这样的迭代最多 4 轮。research 需要判断是否要使用工具进行检索

# Flan -- Scaling Instruction-Finetuned Language Models

> 论文链接 [https://arxiv.org/pdf/2210.11416.pdf](https://arxiv.org/pdf/2210.11416.pdf) ，解读：[nghuyong：Flan-T5: One Model for ALL Tasks](https://zhuanlan.zhihu.com/p/580468546)

这篇工作提出了Flan的微调框架，核心有四点：统一的输入输出格式（4种类型），引入chain-of-thought，大幅提高任务数量，大幅提高模型体积；实现了用一个模型来解决超过1800种几乎全部的NLP任务，通过较低的成本，极大发掘了现有语言模型的泛化性能，让大家看到了通用模型的希望

对指令微调进行了探索：

-   缩放任务数量
-   缩放模型大小
-   对 COT 数据进行微调

最终发现，在上面这仨维度进行指令微调可以显著提高各种模型(PaLM、T5、U-PaLM）、提示设置（零样本、少样本、CoT）和评估基准（MMLU、BBH、 TyDiQA、MGSM、开放式生成、RealToxicityPrompts）。例如，在 1.8K 任务上微调的 Flan-PaLM 540B 指令大大优于 PaLM 540B（平均 +9.4%）。 Flan-PaLM 540B 在多个基准测试中实现了最先进的性能，例如在五次 MMLU 上达到 75.2%。

同时，经过探索，还发布了 Flan-T5 模型，可以与 PaLM 62B 媲美。最后得出结论，指令微调是提高预训练语言模型性能和可用性的通用方法。内部搞了个 Flan-PaLM， 注意这里的语言模型可以进行任意的替换（需要有Decoder部分，所以不包括BERT这类纯Encoder语言模型），论文的核心贡献是提出一套多任务的微调方案（Flan），来极大提升语言模型的泛化性

-   根据是否需要推理（CoT)以及是否需要提供示例（Few-shot），可以讲输入输出划分为四种类型：

-   无 CoT + 无 few shot：左上，输入指令 + 问题，输出答案 （ 普通 使用）
-   有 CoT + 无 few shot：右上，输入指令 + CoT 引导 + 问题，输出理由+答案（CoT）
-   无 CoT + 有 few shot：左下，输入指令 + 提示问题 + 示例问题回答 + 指令 + 问题，输出 答案（ICL）
-   有 CoT + 有 few shot：右下，输入 指令 + CoT 引导 + 示例问题 + 示例问题理由 + 示例问题回答 + 指令 + CoT 引导 + 问题，输出 理由 + 答案（ICL + CoT）

# PaLM: Scaling Language Modeling with Pathways

-   全都不用 bias：可以提升训练稳定性
-   词表：SentencePiece 词表,256k tokens

# GLM: General Language Model Pretraining with Autoregressive Blank Infilling

> 论文链接：[https://aclanthology.org/2022.acl-long.26.pdf](https://aclanthology.org/2022.acl-long.26.pdf)

清华搞得（这个后面要详细补充，毕竟中文开源最大的）

-   任务 ： Autoregressive Blank infilling，大体上来说，首先我们有输入 x1,x2...x6，使用泊松分布进行随机采样，随机 mask 掉 15% 的token 得到输入 part A，被mask 的部分得到输入 Part B。对B 部分进行随机打乱 （下图的 x5 和 x6 前后用[S] span 包围作为整体），将Part A 和part B拼接作为 模型输入。其中attention 的 mask 情况如下图d 所示（part A 是双向的，B部分是单向的）。最终模型输出被 mask 掉的部分。这样模型同时有双向encoder 和 单向 encoder 能力

-   2D position embedding：position 1 是正常文本时所处的位置， position 2 表示 span 内的位置。该编码方法确保模型在重建它们时不知道掩蔽跨度的长度，这种设计适合下游任务，因为通常生成的文本的长度事先是未知的。
-   模型结构：传统 transformer，mask 如上图所示， pre-norm，激活函数 GeLUs

为了能够兼顾NLU和文本生成，对于文档和句子采用不同的空白填充方式。

-   文档：span的长度从原始长度的50%-100%的均匀分布中抽取。该目标旨在生成长文本。
-   句子：限制masked span必须是完整的句子。多个span(句子)被取样，以覆盖15%的的原始标记。这个目标是针对seq2seq任务，其预测往往是完整的句子或段落

这个 span 的设计可以比较好的对下游任务进行适配（相当于留出了各种各样的 slot），使得训练和 fine-tune 见的 gap 比较小

与经典模型的比较：

-   与 BERT 相比：BERT 的各个mask token 间是独立的，对连续 span 和长 span 效果不好
-   与 XLNet 相比：1.需要提前知道要预测的长度。2.训练时间多一倍
