1.  介绍下CBOW 模型和Skip-gram 模型

1.  CBOW 模型是根据上下文去估算当前词语，是正常的单层 MLP(one-hot -> lookup -> 乘输出W 得到 softmax 概率分布）
2.  Skip-gram 模型是根据一个单词来预测其上下文，相比与 CBOW 的输入层权重共享，Skip-Gram 的输出权重$\mathbf{W}^{'}$是共享的。

2.  对比一下CBOW 和skip-gram

1.  训练速度上 CBOW 应该会更快一点。因为每次会更新 context(w) 的词向量，而 Skip-gram 只更新核心词的词向量。
2.  Skip-gram 对低频词效果比 CBOW好。因为是尝试用当前词去预测上下文，当前词是低频词还是高频词没有区别。但是 CBOW 相当于是完形填空，会选择最常见或者说概率最大的词来补全，因此不太会选择低频词

7.  为什么负采样/分层softmax能加快训练？

1.  负采样在优化参数的时候，只更新涉及到的向量参数；放弃用softmax而是用sigmoid，原来的方法中softmax需要遍历所有单词的概率得分。
2.  分层softmax：上面的 Softmax 每次和全部的词向量做内积，复杂度是 O(V)，V 是词典大小。如果考虑把每个词都放到哈夫曼树的叶节点上，用sigmoid做二分类，那么复杂度就可以降为 O(logV)，即树的高度，因为只需要预测从根节点到相应叶节点的路径即可

13.  最好了解一下哈夫曼树的构建

1.  在森林中选择两个根节点的权值最小的树合并，这两棵树的根节点分别作为新树的左右子节点。
2.  新树的根节点的权值是其左右子节点权值的和。
3.  将新树加入森林，同时从森林中移除那两棵被合并的树。
4.  重复以上步骤，直到森林中只剩下一棵树为止，这棵树就是哈夫曼树。

3.  Sigmoid 激活函数的优缺点：

1.  优点：1）连续函数，便于求导。2）Sigmoid函数的输出在(0,1)之间，输出范围有限，优化稳定，可以用作输出层。
2.  缺点：1）sigmoid函数的输出不是0均值的，会导致后层的神经元的输入是非0均值的信号，这会对梯度产生影响。2）sigmoid函数在变量取绝对值非常大的正值或负值时会出现饱和现象，影响梯度更新；3）计算复杂度高，因为sigmoid函数是指数形式。

4.  Tanh 激活函数的优缺点

1.  优点：相比于sigmoid，它是零均值的
2.  缺点：还是饱和与指数形式问题。

5.  为什么要强调零均值？Zigzag 现象
6.  ReLU 函数的优缺点

1.  优点：

1.  在x>0区域上，不会出现梯度饱和、梯度消失的问题。
2.  计算复杂度低，不需要进行指数运算，只要一个阈值就可以得到激活值。
3.  使用ReLU的SGD算法的收敛速度比 sigmoid 和 tanh 快

2.  缺点：

1.  在x<0区域上，会出现凋亡现象。
2.  计算复杂度低，不需要进行指数运算，只要一个阈值就可以得到激活值。
3.  使用ReLU的SGD算法的收敛速度比 sigmoid 和 tanh 快

1.  高斯误差线性单元，通过结合dropout 和非线性激活，赋予网络随机性与非线性，提升网络表现。
2.  BERT 里采用标准正态分布CDF 的近似形式。当然我们也可以把均值和方差当作超参来学。
3.  为什么要用GELU，和ReLU 相比的好处？GeLU 函数在 x 大于0 时输出 x，在负数时，渐进趋于0，但不是像ReLU 那样突变的，而是有一段弯曲，因此相比ReLU 那种突变，传播时更好，

7.  模型训练与调参？

1.  调参的顺序是什么？先学习率，然后batch\_size、隐层维度，学习动量，再往后是网络层数，学习率衰减和其他超参。（总体来说，先学习率，后模型结构）
2.  偏差和方差的定义，分别代表什么？

1.  偏差：度量了学习算法的期望预测与真实结果之间的偏离程度，刻画了学习算法本身的拟合能力。
2.  方差：度量了**训练集的变动**所导致的学习性能的变化，刻画了数据扰动造成的影响。
3.  偏差降低，是因为随着容量的增大，模型的拟合能力越强：对给定的训练数据，它拟合的越准确。
4.  方差增加，是因为随着容量的增大，模型学习得到的泛化性越差：对不同的训练集，它学得的模型可能差距较大。

3.  偏差和方差二者为什么是竞争关系？

1.  在训练充分后模型的拟合能力非常强，训练数据发生的轻微扰动都会导致模型发生显著变化。若训练数据自身的、非全局的特性被模型学到了，则将发生过拟合。

4.  如何评估模型的泛化能力？

1.  Held-out 法：随机选取训练集和验证集，并固定下来
2.  K 折交叉验证：分为K 部分，其中K-1 部分训练，剩下的验证，循环采样
3.  自助法
4.  留一法：对于N 个样本，用 N-1 训练，剩下那个1 做验证。

5.  Batch\_size 大小对训练的影响：

1.  大的 batch\_size 的稳定性更高，因为模型训练曲线会更加平滑。
2.  训练稳定会使得训练速度变快些，毕竟走的弯路少了。
3.  在相同 epoch 的前提下，大的 batch\_size 所需训练时间更少，不过如果不更改学习率的话，可能带来迭代次数不足的问题

6.  学习率对模型训练的影响，一般怎么设置学习率？

1.  学习率太小模型学不动，loss 降得太慢，拟合能力弱
2.  学习率过大梯度可能爆炸，也可能不收敛，在极值点周围晃荡
3.  一般来说，SGD 的话初始学习率用0.1，Adam 的用0.001。数据集特别大的话，学习率会更小，训练语言模型的时候用过1e-4，finetune 是用3e-5 这种

7.  embedding层的embedsize可以小一些（64 or 128），之后LSTM或CNN的hiddensize要稍微大一些（256 or 512）

2.  基于动量的优化算法

1.  为什么用到动量？动量梯度下降（Momentum Gradient Descent）是一种优化算法，它在传统梯度下降的基础上增加了动量项，以加速学习过程中的收敛，并减少震荡。动量项是之前梯度的加权平均，它可以帮助优化算法在相关方向上保持运动，同时抑制振荡，这样可以在某种程度上克服梯度下降中的一些问题，比如Hessian矩阵的病态条件（ill-conditioned Hessian matrix）和 随机梯度的方差
2.  **Hessian矩阵的病态条件：**Hessian矩阵的病态条件是指Hessian矩阵（二阶导数矩阵，描述目标函数局部曲率的矩阵）的条件数非常大，这意味着目标函数的曲率在不同方向上变化很大。在这种情况下，梯度下降可能会在某些方向上前进得非常缓慢，而在其他方向上前进得非常快，这会导致收敛速度慢和训练过程中的震荡。

1.  **动量优化算法通过以下方式缓解这个问题：**

1.  **加速收敛：动量项考虑了之前梯度的信息，使得优化算法在梯度方向一致的维度上加速，这有助于更快地穿过病态条件区域。**
2.  **减少震荡：动量项同样可以平滑不一致的梯度更新，减少在病态条件下出现的震荡现象，特别是在高曲率和陡峭的方向上。**
3.  **穿越鞍点：动量有助于优化算法穿越鞍点（saddle points），这些点在某些方向上是局部最小值，而在其他方向上是局部最大值。动量可以帮助算法保持在梯度较小的方向上的运动，而不会被鞍点困住。**

3.  **随机梯度的方差：**随机梯度下降（Stochastic Gradient Descent, SGD）的一个主要问题是高方差，这可能导致优化过程中的震荡和不稳定。

1.  动量方法可以帮助加快收敛并减少震荡。它通过结合之前梯度的加权平均来平滑更新，减少单个梯度估计的波动。

1.  什么是卷积？

1.  卷积运算通常涉及到将一个函数（例如卷积核或滤波器）“翻转”并在另一个函数（例如信号或图像）上“滑动”以产生新的函数。这个过程称为卷积，它是一种数学运算，用于合并两个函数以反映它们之间的关系。

2.  卷积公式为什么长这个样子？和互相关函数的关系？为什么DL 中用互相关函数？

4.  优点：在不做池化损失信息的情况下，加大感受野，让每个卷积的输出都包含较大范围的信息。在图像需要全局信息，或者语音、文本需要较长序列信息的问题中，空洞卷积都能很好的应用。
5.  缺点：

1.  网格效应(Gridding Effect )。如果仅仅多次叠加多个 dilation rate=2 的 3x3 的卷积核时，会发现：并不是所有的输入像素都得到计算，也就是卷积核不连续。
2.  长距离信息可能与任务无关。采用空洞卷积可能对大物体的分割有效果，但是对于小物体的分割可能没有好处。如何同时处理不同大小的物体，则是设计好空洞卷积网络的关键。

6.  解决网格效应方案：

1.  叠加的空洞卷积的dilation rate 不能有大于1的公约数。这是为了对抗网格效应。如：[2,4,6] 不是一个好的三层空洞卷积，因为会出现网格效应
2.  将dilation rate 设计成锯齿状结构。这是为了同时满足小物体、大物体的分割要求。如[1,2,5,1,2,5] 的循环结构。
3.  最后一层的空洞卷积的dilation rate 最大，且dilation rate 小于等于卷积核的大小。这也是为了对抗网格效应。

2.  1x1 卷积：1x1 卷积并不是复制输入，它会进行跨通道的卷积。它有三个作用：

1.  实现跨通道的信息整合
2.  进行通道数的升维和降维
3.  在不改变输入尺寸的前提下，大幅度提升非线性（后面常跟一个ReLU）

3.  多尺寸卷积核：分别使用多个不同尺寸的卷积核从而获得不同尺度的特征。然后将这些特征拼接起来。优点是可以获得多粒度特征，缺点是参数数量比单尺寸卷积核要多很多，这就使得计算量和存储量都大幅增长。
4.  卷积核替代:

1.  原理：用多个小卷积层的堆叠来代替较大的卷积核. 假设大卷积核的宽度是k，则每经过一层，输出的宽度减少了k-1。假设希望通过n个宽度为的小卷积核来代替，则为了保持输出的大小一致，需要满足：。比如说用2个3x3 的卷积核替代1 个5x5 的卷积核，可以在获得相同感受野的前提下，减少5x5 – 2x3x3 = 7 个参数。
2.  优点：

1.  可以实现与大卷积层相同的感受野。
2.  具有更大的非线性，网络表达能力更强。
3.  具有更少的参数数量

3.  缺点：加深了网络的深度，容易引发梯度消失等问题，从而使得网络的训练难度加大。

5.  非对称卷积核：非对称卷积核分解，将nxn 卷积替换为1xn 卷积和nx1 卷积。

1.  优点：节省参数量
2.  缺点：在Inception v2 论文中作者指出：对于较大的特征图，这种分解不能很好的工作；但是对于中等大小的特征图（尺寸在12～20 之间），这种分解效果非常好。

4.  介绍一下RNN 中的梯度消失或爆炸问题？是由于什么引起的？和DNN 中的梯度消失或爆炸有什么区别？

1.  为什么有梯度消失/爆炸：当梯度通过时间反向传播时，需要连续乘以网络中的权重。如果这些权重小于 / 大于 1（绝对值），梯度会随着每一步的传播而指数级减小，导致梯度消失 / 爆炸。RNN的这些问题主要是由于其设计中的权重在每个时间步都是共享的，且梯度必须通过这些共享权重在时间步之间传播。当序列很长时，这种梯度的累积效应变得尤其显著。
2.  **RNN 所谓梯度消失的真正含义是，梯度被近距离梯度主导，导致模型难以学到远距离的依赖关系。这是因为在梯度消失/爆炸之前，还是有一部分参数能正常更新的。**
3.  但这种长期依赖性是要学习的，且长期依赖性的长期梯度贡献毕竟不会太大，因此切掉过小的梯度是不可取的。为了存储记忆并对小扰动具有鲁棒性，RNN 必须进入参数空间中的梯度消失区域(Bengio et al., 1993, 1994a)。具体来说，每当模型能够表示长期依赖时，长期相互作用的梯度幅值就会变得指数小（相比短期相互作用的梯度幅值）。这并不意味着这是不可能学习的，由于长期依赖关系的信号很容易被短期相关性产生的最小波动隐藏，因而学习长期依赖可能需要很长的时间。
4.  一个是在相同时间步上的累积，一个是在网络深度和 Sigmoid 的饱和性带来的

5.  用公式推导展示梯度消失/爆炸的产生原因
6.  怎么能解决/减缓梯度消失或爆炸呢（通用角度）？

1.  跳跃链接：之前的时间步直连到当前时间步，可以减缓梯度消失，但不能解决梯度爆炸
2.  激活函数的选择：使用像ReLU这样的激活函数来减少梯度消失的问题，因为它们对于正输入的梯度是常数（不会随着传播而衰减）。
3.  梯度剪裁（Gradient Clipping）：当梯度超过一定阈值时，对其进行剪裁，以防止梯度爆炸。
4.  使用更高级的RNN架构：如长短期记忆网络（LSTM）和门控循环单元（GRU），它们通过引入门控机制来更好地控制信息的流动，从而减缓梯度消失和爆炸的问题。
5.  删除连接：主动删除时间跨度为1的连接，用更长的连接替换它们
6.  渗漏单元：前面看到长期依赖的问题根源是梯度的累计，因此我们可以使梯度接近1，这可以通过线性自连接单元实现。如 h(t)=αh(t−1)+(1−α)x(t)，当 α接近1时，过去的信息被记住，当 α 接近0时，当前输入的信息被使用。其实这里和LSTM的思想很接近了。怎么看起来像highway？

10.  LSTM 是怎么解决长期依赖问题的？

1.  在Cell state 路径上，只有相加相乘累积操作，其中相乘部分贡献由遗忘门 给出，梯度流最稳定。在其他路径上，LSTM 的梯度流和普通 RNN 没有太大区别，依然会爆炸或者消失。由于总的远距离梯度 = 各条路径的远距离梯度之和，即便其他远距离路径梯度消失了，只要保证有一条远距离路径（就是上面说的那条高速公路）梯度不消失，总的远距离梯度就不会消失（正常梯度 + 消失梯度 = 正常梯度）。因此 LSTM 通过改善一条路径上的梯度问题拯救了总体的远距离梯度。
2.  Cell state 形成信息高速路，减少中间的信息损耗，使得模型输出层可以看到之前不同时间步的信息
3.  门机制：用门控制信息流动，隐层状态采用加性更新（cell state 上只有一个开关和加性更新），不做非线性变换

11.  LSTM 是怎么缓解梯度消失/爆炸的？（公式推导反向传播），需要注意的是，LSTM 的梯度消失是指远程位置（开始）那梯度的消失，整体梯度是所有时间步梯度的累加，不太会消失。主要还是cell state，它几乎不经过任何非线性变换。

1.  如何在模型层面提升NER性能？集中精力在embedding层下功夫，那就是**引入丰富的特征**：比如char、bigram、词典特征、词性特征、elmo等等，还有更多业务相关的特征；在垂直领域，如果可以预训练一个领域相关的字向量&语言模型，那是最好不过的了。总之，**底层的特征越丰富、差异化越大越好。**我们需要构造不同视角下的特征。
2.  如何构建引入词汇信息（词向量）的NER？Lattice LSTM 及其变体
3.  如何解决NER实体span过长的问题？尝试引入**指针网络+CRF**构建**多任务学习**解决。
4.  如何客观看待BERT在NER中的作用？NER 作为基础模块，不适合上太大的模型，因此如果使用也要对其进行蒸馏。经过试验，最少也得保留4层才能有较好的效果。
5.  如何冷启动NER任务？先尝试用规则和领域词典试试能不能满足要求，而后再尝试人工标注数据。可以先通过标注少量数据，而后用PTM 模型跑一下看看效果，而后利用PTM 模型辅助标数据。
6.  如何缓解NER标注数据的噪声问题？交叉验证，而后人工清洗数据。
7.  如何克服NER中的类别不平衡问题？数据增强、Loss 加权重、加规则模板、加标注样本。。。等
8.  如何对NER任务进行领域迁移？无论是特征，还是模型，领域性都比较强，迁移效果一般。
9.  如何有效解决低资源NER问题？上PTM、加领域字典、加规则。。
10.  如何解决低耗时场景下的NER任务？轻量级模型+轻量级特征
11.  **如何让NER系统变得“透明”且健壮？：**构建一套**多层级、多粒度、多策略**的NER系统

1.  多层级的NER系统更加“透明”，可以回溯实体的来源（利于医学实体消歧），方便“可插拔”地迭代优化；同时也不需要构建数目众多的实体类型，让模型“吃不消”
2.  多粒度的NER系统可以提高准召。如，第⼀步抽取⽐较粗粒度的实体，通过模型+规则+词典等多策略保证⾼召回；第⼆步进⾏细粒度的实体分类，通过模型+规则保证⾼准确。
