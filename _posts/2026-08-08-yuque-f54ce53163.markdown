# OpenAI Codex —— Agent / Harness 深度解剖（系列总览）

> 一套基于 OpenAI Codex 开源仓库（`github.com/openai/codex`，Apache-2.0，Rust monorepo）**一手源码**逐层写就的剖析系列。目标只有一个：读完这 14 篇，你能从"会用 agent 工具的人"成长为**能设计、能审阅、能自建 Agent / Harness 系统的专家**。

## 为什么写这套

市面上的 Agent 文章大多停在"提示词技巧"或"调 API"层面。但一个**生产级 coding agent** 的真正护城河，是它底下那套 **Harness（给模型套上的"身体与操作系统"）**：上下文怎么拼、工具怎么管、命令怎么沙箱、长任务怎么不忘目标、多代理怎么编排、运行时怎么解耦前端……这些工程问题，Codex 都用可核查的代码给了答案。

本系列每篇都遵循同一结构：**原理讲解 → 源码剖析（真实** `file:line` **+ 符号 + 关键片段）→ 心智模型 / 可迁移经验**，并在关键处与 Claude Agent SDK、LangGraph、WorkBuddy/OpenClaw、MCP 生态做对照，帮你建立领域地图。

## 阅读路径（14 篇，建议顺序）

1.  **Harness 解剖学：model + harness 与 Codex 全景架构** —— 先建立"framework / runtime / harness"分层心智模型与 Codex 整体 crate 地图。

2.  **Agent 循环：一次 turn 的生命周期** —— 看懂 `run_turn` 主循环，这是所有 agent 的心脏。

3.  **上下文工程：从片段拼装到 AGENTS.md** —— 模型"看到的世界"是怎么一点点拼出来的。

4.  **工具层：注册表、路由与工具设计** —— 工具是 agent 的手脚，设计优劣决定能力边界。

5.  **代码即工具** —— 为什么 coding agent 最锋利的工具是"写代码/打补丁"本身。

6.  **Skills：可复用能力与渐进式加载** —— 不改动核心就能给 agent 加能力，且按需注入避免上下文膨胀。

7.  **MCP 与外部工具生态** —— 用统一协议把 agent 接进外部世界。

8.  **安全自治：策略、沙箱、权限、审批与守护** —— 自治与安全的矛盾如何靠纵深防御化解。

9.  **长程作业：压缩、目标与记忆** —— 上下文窗口有限，任务却很长，怎么"压缩历史不丢目标"。

10.  **多代理编排：从 orchestrator 到 agent graph** —— 任务分解、agent 树、跨代理通信。

11.  **评估与自我验证** —— agent 凭什么相信自己做对了（跑测试、读错误、重试）。

12.  **可观测性与遥测：让 agent"看见"系统** —— 决策黑盒如何被回放与度量。

13.  **运行时与协议** —— 为什么把核心引擎与前端解耦，是 harness 的架构基石。

14.  **工程实践与未来：造你自己的 harness** —— 综合提炼设计原则 + 一份可执行的"自建 harness 检查清单"。

## 一句话心智模型

> **模型是大脑，Harness 是身体与操作系统。** Codex 把"推理"与"执行"彻底分离：一个被多前端复用的 `codex-core` 引擎负责思考，隔离的 `exec-server` 在沙箱里动手，中间靠强类型协议通信——这就是一个生产级 agent 的骨架。
