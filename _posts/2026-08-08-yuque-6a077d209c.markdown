## 〇、执行摘要（TL;DR）

如果只看五句话：

1.  **CERN 2026 上半年在 arXiv 的产出创下近十年同期新高**：带 CERN 报告号的论文 363 篇，较 2025 年同期（270 篇）增长 **34.4%**，也高于 2018 年的历史高点（337 篇）。这是 Run 3 数据集完成收官前的"论文洪峰"。

2.  **超对称已经从 CERN 的主线退居支线**。434 篇 CERN 论文中，超对称相关仅 **18 篇（4.1%）**，排在味物理（27.9%）、希格斯（15.0%）、重离子（11.1%）、顶夸克（10.4%）、电弱/SMEFT（9.4%）之后。CERN 理论部（CERN-TH）126 篇论文中，真正涉及超对称的只有 **4 篇**，且全部是超引力宇宙学与软件工具，**零篇**弱标度 SUSY 唯象学。

3.  **对撞机超对称唯象学的长期萎缩已成定局**。以"squark/gluino/neutralino/chargino/slepton/higgsino/MSSM"为口径，同期论文数从 2014 年的 209 篇跌至 2026 年的 **58 篇**（−72%）；同期 hep-ph 总量却从 3808 涨到 5183（+36%）。占比从 **5.49% 崩塌至 1.12%**，五倍级的相对衰减。

4.  **但"超对称搜索"本身并未停滞，而是发生了范式转移**：从"高质量、强产生、大缺失能量"转向 **压缩质量谱（Δm 亚 GeV）+ 长寿命粒子（位移顶点/消失径迹）+ R宇称破坏（RPV）+ 机器学习重构**。2026 上半年 12 篇 CERN-EP 超对称实验论文中，**9 篇**属于这四类"难信号"，其中 7 篇明确使用了神经网络/图神经网络。

5.  **唯一值得盯住的异常**：CMS 在 X→YH→bbbb 通道于 (m\_X, m\_Y) = (600, 400) GeV 处观察到 **局域 3.47σ / 全局 2.44σ** 超出（arXiv:2605.02848），论文明确在 **NMSSM** 框架下解释。这是本窗口内唯一带超对称解释的显著性超出。

### 1.1 "CERN 产出"如何界定

arXiv 的 Atom API **不返回作者单位（affiliation）**，因此无法直接按"作者属于 CERN"筛选。本报告采用**报告号（report number）代理法**，这是学界公认的最强归属信号：

### 1.3 已知局限（必须诚实说明）

-   **无单位字段**：不带 CERN 报告号但由 CERN 员工/Fellow 撰写的论文会被漏掉。真实"CERN 人员参与"的论文数应显著高于 434。

-   **合作组论文的归属**：ATLAS/CMS 论文是全球 3000+ 人署名，计入"CERN 产出"是按 CERN-EP 报告号的机构惯例，不等于"CERN 本部独立完成"。

-   **关键词召回率**：摘要不含关键词的论文会漏检（如某些用"electroweakino"以外表述的分析）。

-   `journal_ref` **填充滞后**：基准集中仅 13.1% 已带期刊号/DOI，因为大部分是 3 个月内的新预印本，不代表发表率低。

-   **版本合并**：按 arXiv 主 ID 去重（v1/v2/v3 视为同一篇）。

#### ① ATLAS 消失径迹：一次教科书级的"死角清扫"

**arXiv:2603.08315 · JHEP 07 (2026) 152 · 137 fb⁻¹ @ 13 TeV**

这是本窗口方法论上最扎实的一篇。目标是纯 higgsino / 纯 wino 场景——它们的 chargino 与最轻中性微子质量劈裂仅由标准模型玻色子的**圈图修正**决定（higgsino 约 0.3 GeV，wino 约 0.16 GeV），导致 chargino 寿命在 0.01–10 ns，飞行几厘米后衰变成一个中性微子和一个极软的 π±，径迹在探测器内层"凭空消失"。

技术亮点：

-   定义了**只有 3 层或 4 层内层探测器击中**的径迹信号区——这已逼近径迹重建的物理极限。

-   对 3 击中径迹，进一步用**机器学习专用算法**判定是否伴随一条低能 π±，把 3-hit 区间又劈成两个正交子区。

-   本底完全数据驱动。

结果：wino chargino 在 τ ≈ 1 ns 排除到 **880 GeV**；higgsino 在 τ < 0.03 ns 排除到 **225 GeV**。

**为什么重要**：纯 higgsino 是"自然超对称"（naturalness）最难被排除、也最应该轻的粒子。这篇论文把 higgsino 的观测限推到 225 GeV，虽然距离自然性偏好的 100–300 GeV 区间上沿仍有余量，但**LEP 遗留的 103 GeV 限已经被彻底超越**。配合 CMS 2604.25604 的 185 GeV（针对更极端的 Δm 0.28–1.15 GeV），压缩 higgsino 这个"最后的避难所"正在被两个实验从不同 Δm 区间夹击封闭。

#### ② CMS 压缩谱软径迹：参数化神经网络的胜利

**arXiv:2604.25604 · 138 fb⁻¹ @ 13 TeV**

与 ①互补：ATLAS 攻 Δm 极小（消失径迹），CMS 攻 Δm 0.3–1 GeV（软径迹可被重建但动量极低）。

-   chargino → 中性微子 + 低动量 π，π 形成一条软的、可能略微位移的径迹。

-   用**参数化神经网络**（parameterized NN，以 Δm 和质量为条件参数）同时处理运动学与碰撞参数信息，避免为每个质量点单独训练。

结果：Δm ∈ [0.28, 1.15] GeV 区间内，chargino 质量排除到 **185 GeV**。

**判读**：注意排除区是**双侧**的——Δm 太小则径迹不可重建，Δm 太大则 π 不再软。这意味着实验灵敏度是"带状"的，模型空间不是被从下往上推平，而是被**打出一个个洞**。这正是当代 SUSY 搜索的真实形态，也是为什么"排除限"这个概念越来越需要配合再解释工具（见 ⑤⑧）来理解。

#### ③ ATLAS Run-3 位移顶点：164 fb⁻¹ 的分水岭

**arXiv:2603.01991 · PLB 878 (2026) 140509 · 164 fb⁻¹ @ 13.6 TeV（2022–2024）**

这是本窗口内**首批以 Run 3 数据为主体**的超对称相关搜索之一。164 fb⁻¹ 已经超过 Run 2 全量（140 fb⁻¹），且能量从 13 TeV 提升到 13.6 TeV。

信号：≥1 个高质量位移顶点（多径迹）+ ≥1 个大碰撞参数 μ 子，且**不要求 μ 与顶点关联**——这是一个刻意放松的设计，用来覆盖顶点重建失效但轻子仍可见的相空间。本底全数据驱动。

结果：无超出，给出 RPV SUSY 多个基准模型的截面上限。

**判读**：Run 3 数据开始进入超对称搜索主流。按 13.6 TeV 相对 13 TeV 的截面增益（对 TeV 级色荷粒子约 +20~40%）叠加亮度增益，Run 3 全量（预计 Run 1–3 合计约 500 fb⁻¹）对强产生 SUSY 的质量触及能力大致再推高 **10–15%**——即 gluino 极限从 ~2.3 TeV 推到 ~2.6 TeV 量级。这与我们在检索中看到的公开报道一致。**这是一个残酷的算术：亮度翻倍只换来质量极限约 10% 的提升**，这正是 SUSY 搜索边际收益递减的定量表达。

#### ④ CMS 长寿命 stau + 图神经网络

**arXiv:2601.17576 · JHEP 07 (2026) 102 · 138 fb⁻¹**

首次使用**专为位移 τ 轻子设计的图神经网络**识别算法。物理动机是规范传递超对称破缺（GMSB）中 stau 作为次轻超对称粒子（NLSP）具有宏观寿命。

结果：cτ = 50 mm 时排除 stau 质量 126–260 GeV（最大混合）/ 90–425 GeV（质量简并）；m\_stau = 200 GeV 时排除 cτ ∈ [21, 94] mm（最大混合）/ [6, 333] mm（简并）。

**判读**：注意"质量简并场景"的排除范围（90–425 GeV）显著宽于"最大混合"（126–260 GeV）。这是因为简并场景下三代 slepton 简并产生，截面高约 3 倍。**同一份数据、同一个探测器，仅仅因为模型假设不同，排除范围差了 2.5 倍**——这是 SUSY 排除限最容易被误读的地方，也是为什么"gluino 已被排除到 2.5 TeV"这类陈述在脱离模型语境后几乎无意义。

#### ⑤ ATLAS 变 RPV 耦合强度再解释：本窗口最有方法论野心的一篇

**arXiv:2603.15007 · 140 fb⁻¹**

把 **13 个**已发表的 ATLAS 搜索（原本分别针对 RPC 和 RPV 优化）放到同一个框架下重新解释：以 RPV 耦合强度 λ 为连续参数，扫描"LSP 瞬时衰变 ↔ 长寿命"的整个过渡区。

这解决了一个长期的结构性漏洞：传统搜索要么假设 LSP 稳定（大 MET），要么假设 LSP 长寿命（位移顶点），**中间那段"耦合不大不小、飞行几毫米"的相空间无人认领**。

结果覆盖 gluino、stop、stau、chargino/neutralino 四类粒子，在 λ 的多个数量级上给出连续排除。

**判读**：这标志着实验合作组的工作重心正从"做新搜索"转向"**把已有搜索的覆盖面填满**"。从科学产出效率看，这是理性的——在没有信号的情况下，压榨既有数据的模型覆盖度，比新增一个窄目标搜索的边际信息量更高。但它也是一个软性信号：**合作组自己也认为，剩余的发现空间主要在"缝隙"而非"前沿"**。

#### ⑥ ATLAS 顶超子对产生：主线搜索的现状

**arXiv:2603.16191 · 140 fb⁻¹ (13 TeV) + 53 fb⁻¹ (13.6 TeV)**

最"经典"的一篇：stop 对产生 → 两个在壳顶夸克 + 两个中性微子，双轻子 + b 喷注 + 大 MET。用机器学习分类器在宽运动学相空间做信号-本底分离。

结果：stop 排除到 **1060 GeV**（中性微子 560 GeV），比此前同通道 ATLAS 分析**改进约 10%**。

**判读**：这条数字最能说明问题。stop 是自然超对称的核心（它决定希格斯质量的圈图修正），2015 年 Run 2 早期的限在 ~800 GeV，如今 140+53 fb⁻¹ 才推到 1060 GeV。**在 1 TeV 的 stop 下，希格斯质量的精细调节已达 1% 量级**——理论动机层面，"自然的 SUSY"在这个通道上已基本出局，剩下的是"存在但不自然"的可能性。

#### ⑦ CMS X→YH→bbbb：本窗口唯一带超对称解释的显著性超出

**arXiv:2605.02848 · 138 fb⁻¹**

搜索重标量 X 衰变为 125 GeV 希格斯 H 加上一个新标量 Y，二者各自衰变为 bb̄。扫描 m\_X ∈ [400 GeV, 1.6 TeV]，m\_Y ∈ [60 GeV, 1.4 TeV]。

**结果：在 (m\_X, m\_Y) = (600, 400) GeV 处观察到局域 3.47σ / 全局 2.44σ 超出**，论文明确在 **NMSSM**（次最小超对称标准模型）框架下解释。

**判读（必须冷静）**：

-   全局 2.44σ 意味着在整个扫描空间中，随机涨落产生同等或更强超出的概率约 1.5%——**这在粒子物理里连"迹象（evidence, 3σ）"都算不上**。

-   但它值得盯，因为：(a) X→SH 级联衰变是扩展标量部门（NMSSM 是其超对称实现）的**特征信号**；(b) 我们的检索显示，ATLAS 曾在 A→ZH→Ztt̄ 通道于 (m\_A, m\_H) = (650, 450) GeV 处观察到 2.85σ 局域超出，**质量尺度相近**，虽未被 CMS 证实；(c) 唯象界已有多篇论文（如 `2606.02069` μ 项扩展 NMSSM 中的轻标量超出与重标量级联、`2602.13976` 左右对称超对称模型中的 95/125 GeV 希格斯超出）在构建能同时容纳这些偏差的模型。

-   **判断**：这是一个"值得下注 5%，不值得下注 50%"的信号。Run 3 全量数据（约 500 fb⁻¹ 合计）足以在 2027–2028 年给出决定性结论。

#### ⑧ CERN-TH 的超对称：4 篇，无一涉及对撞机

**2603.02389 / 2606.31975（超引力暴胀与再加热）、2606.02693（N=4 SYM 等离子体）、2607.18222（HyperIso 软件）**

-   **2603.02389 与 2606.31975** 是同一研究线的两篇（作者数均为 5，属经典的 Ellis–Nanopoulos–Olive 系无标度超引力暴胀纲领）。前者研究无标度超引力暴胀模型中的辐射修正，发现**原始的 Wess-Zumino 超势模型在大暴胀子场值下辐射修正会主导动力学，使其对 CMB 的预言失效**；但 Cecotti 类模型在场值 ≲ 8 M\_Pl 时修正极小，与 Planck 数据的一致性得以保持。后者研究这类模型的再加热温度与 (n\_s, r) 预言。

-   **2606.02693** 用 N=4 超对称 Yang-Mills 作为强耦合等离子体的**计算工具**（AdS/CFT 对偶），研究重夸克在夸克胶子等离子体中的随机动力学。这里的"超对称"完全是技术手段，与自然界是否超对称无关。

-   **2607.18222（HyperIso）** 是 SuperIso 的现代化重写，用 C++ 内核 + Python/CLI/GUI 接口，可对接 MARTY 自动计算 BSM Wilson 系数。支持超对称模型只是其"支持的模型之一"。

**这是全报告最锋利的一个事实**：CERN 理论部 126 篇论文中，**没有任何一篇是弱标度超对称唯象学**（如 MSSM 参数空间扫描、SUSY 暗物质遗迹丰度、超对称对 LHC 信号的预言）。作为对比，CERN-TH 在 2026 上半年产出了大量精确 QCD（NNLO/N³LO 计算、部分子簇射、Feynman 积分）、味物理（B→X\_sγ 到 N³LO、|V\_cb|、b 重子寿命）、轴子/暗区（"QCD 轴子能藏多好"、暗荷 ALP、Axiverse）、格点 QCD（μ 子 g−2 的强子真空极化高阶贡献）与宇宙学（原初黑洞、暴胀、一阶相变引力波）方向的论文。

**这不是资源分配的偶然，是学术判断的集体表达。**

## 五、唯象学界的应对：SUSY 社群在做什么

CERN 之外，2026 上半年有 103 篇 hep-ph/hep-ex 主分类的超对称论文（非 CERN 报告号）。它们的方向分布揭示了 SUSY 社群的**四条自救路径**：

### 路径 A：向"未来对撞机"转移预期（最主流）

-   `2601.01066` Supersymmetry at High Luminosity LHC

-   `2602.09187` pMSSM 对比完整模型：HL-LHC 上顶超子发现的"极佳前景"

-   `2602.06957` 重访重子数破坏 MSSM 的电弱微子部门（HL-LHC + 深度神经网络）

-   `2604.06103` 希格斯工厂在最困难场景（最低截面 stau）下的 SUSY 触及能力

-   `2605.23793` FCC-ee 上 GMSB 场景的带电长寿命粒子

**判读**：把发现时间表推迟到 HL-LHC（2030s）乃至 FCC（2040s+）。这在科学上合理，在社会学上是典型的"预期展期"。

### 路径 B：转向暗物质与直接探测互补

-   `2602.14088` 自然 SUSY 中轻 bino-higgsino 暗物质的现状与前景

-   `2603.18412` 在最新实验结果下重访 bino-slepton 共湮灭暗物质

-   `2607.05648` "盲点"能否拯救自然超对称中的中性微子暗物质？

-   `2607.20588` MSSM 中 higgsino-核子散射在 NLO 下的消失

-   `2606.31013` 轻 higgsino 的互补探测：电弱精确测量 + 暗物质直接探测

-   `2606.05299` 用重元素古探测器（paleodetector）搜寻 higgsino 暗物质

**判读**：`2607.20588` 和 `2607.05648` 尤其值得注意——它们在计算**为什么 higgsino 暗物质可能对直接探测实验"隐身"**（散射截面的 NLO 抵消、参数空间盲点）。这是一种防御性研究：解释"为什么至今没看到"，而非预言"在哪里能看到"。

### 路径 C：向 GUT / 味物理 / 中微子等结构问题迁移

-   `2607.04250` 最小超对称 SO(10) 与普适软谱的更新分析

-   `2603.22418` 最小超对称 SU(5) 中核子衰变的普朗克标度效应

-   `2603.24152`/`2603.25825`/`2606.29811` 超对称 Pati-Salam 模型系列（LHC Run-3、汤川统一、轻中性微子暗物质）

-   `2601.18237` 重访 RPV SUSY 中的 μ-e 转换

-   `2606.25936` 双线性 RPV wino-LSP 的中微子振荡 + LHC 互补探测

**判读**：把 SUSY 从"TeV 标度可发现的理论"降格为"高标度统一理论的必要脚手架"。这个定位不需要 LHC 发现任何东西就能成立，是最安全的退路。

### 路径 D：转做工具与统计方法

-   `2603.12119` FlexibleSUSY 对接 HiggsTools（从拉氏量到希格斯物理约束的自动化）

-   `2604.25009` NMSSMScanner：NMSSM 参数空间的高效扫描

-   `2605.22330` 符号分类驱动的 LHC 在线 BSM 全局拟合

-   `2607.07505` SModelS v3.0 复现 ATLAS pMSSM 扫描，并研究统计组合的增益

**判读**：`2607.07505` 的结论非常坦率——它发现即使把 CMS 结果一并纳入并做统计组合，**pMSSM 中仍有相当一部分轻电弱微子参数空间在 LHC 限制下存活**，并"强调需要广泛、多面的方法来最大化灵敏度、堵住漏洞"。这是本窗口内对"SUSY 是否已死"这个问题最负责任的回答：**没有死，但活着的部分越来越难被证伪，这本身就是理论健康度的警讯**。

### 附：值得单独一提的三篇

-   `2603.04664` **"50 Years of SUSY and SUGRA, circa 1974-2024, and Future Prospects"** —— 领域的五十年史，本身就是一种阶段性总结的信号。

-   `2607.07921` **"Serendipitous supersymmetric solution to the strong CP problem"** —— 试图让 SUSY 顺带解决强 CP 问题，属于"为 SUSY 寻找新动机"的典型尝试（原有动机：等级问题、暗物质、耦合常数统一，均已被削弱）。

## 七、七个结构性判断

### 判断 1：超对称已完成从"假说"到"工具箱"的身份转换

498 篇狭义 SUSY 论文中 58.2% 主分类为 hep-th/math.\*。超对称今天的主要价值是：可积系统的求解结构、AdS/CFT 的计算脚手架、弦论紧化的一致性条件、凝聚态拓扑相的分类工具。**它作为"自然界在 TeV 标度的对称性"这一原始命题，支持者已成少数。**

### 判断 2：CERN 理论部已用脚投票

126 篇 CERN-TH 论文，0 篇弱标度 SUSY 唯象。理论部的资源全面流向：精确 QCD（NNLO/N³LO/Feynman 积分）、味物理（|V\_cb|、B 衰变形状因子、CKM 结构）、轴子与暗区、格点 QCD、宇宙学与引力波、以及新兴的机器学习方法论。**任何关于"SUSY 仍是 CERN 理论重点"的说法都与数据不符。**

### 判断 3：实验搜索没有停，但已进入"填缝期"

12 篇 CERN-EP 超对称论文中，9 篇针对压缩谱 / 长寿命 / RPV / 再解释这四类"难信号"。ATLAS 的 13 搜索联合再解释（`2603.15007`）和 SModelS 的 pMSSM 复现（`2607.07505`）都指向同一件事：**当代 SUSY 搜索的核心产出不再是"推高质量极限"，而是"提高参数空间覆盖率"。**

### 判断 4：亮度的边际收益已经很低

Run 2（140 fb⁻¹）到 Run 2+早期 Run 3（193 fb⁻¹），stop 极限从 ~960 GeV 推到 1060 GeV，改进 **约 10%**。这是因为强产生截面随质量指数下降，质量触及能力 ~ log(亮度)。**HL-LHC 的 3000 fb⁻¹ 相对现在也只能再推 30–40%**，即 gluino 到 ~3 TeV、stop 到 ~1.5 TeV。想要质变必须换更高能量的机器，而这是 2040 年代的事。

### 判断 5："自然超对称"在实验上已实质出局

-   stop 1.06 TeV → 希格斯质量精细调节约 1% 量级

-   higgsino 185–225 GeV → 自然性偏好区间的下沿已被吃掉

-   gluino 1.9–2.5 TeV → 远超任何自然性论证的舒适区

剩下的 SUSY 是"存在但不解释等级问题"的 SUSY（分裂超对称、高标度 SUSY、GUT 尺度 SUSY）。**这类 SUSY 无法在对撞机上被证伪，也就无法被证实。**

### 判断 6：值得监控的唯一异常是 (600, 400) GeV 的 NMSSM 级联

CMS `2605.02848` 的 3.47σ 局域超出，与 ATLAS 此前 A→ZH 通道 (650, 450) GeV 的 2.85σ 在质量尺度上接近。两者若在 Run 3 全量数据中同向增强，将是二十年来最强的 SUSY 相关信号。**当前概率评估：低（全局仅 2.44σ），但监控成本为零。**

### 判断 7：CERN 的产能创新高，说明问题不在资源而在方向

363 篇 CERN 报告号论文是 2014 年以来同期最高（比 2018 年高点还多 26 篇）。**CERN 没有变弱，它只是不再往超对称这个方向使劲了。** 这是一个健康的、由数据驱动的科学共同体的正常行为——但对超对称而言，这是比任何一条排除限都更致命的信号。
