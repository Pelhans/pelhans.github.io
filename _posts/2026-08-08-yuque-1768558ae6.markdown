# 什么是 prompt

对输入文本x 进行修改 变成 x'，包含两步：

-   应用一个模板，这是一个文本字符串，有两个槽：一个输入槽 [X] 用于输入X，另一个答案槽 [Z] 用于中间生成的答案文本Z，该答案文本Z稍后将映射到答案集 y
-   用输入文本 x 替换 填充槽 [X]

举个例子， x 输入是 “我喜欢这部电影", 模板是 [X] 总体而言，这是一部 [Z] 电影"。 把x 放进去就变成 "我喜欢这部电影。总的来说，这是一部[Z]电影" 。Z 可以是 ”好“， ”坏“，”糟糕“等等词汇。

promot 从槽的位置上来看有两种主要类型：

-   完形填空提示（cloze prompt）：在文本中间加槽，mask 类任务/模型效果好
-   前缀提示（prefix prompt）：前缀提示，生成相关的任务效果更好

# 预训练模型选择

1.  训练目标：对特定提示任务的适用性方面比较重要，比如自回归的特别适合前缀提示，重建目标更适合完形填空提示

1.  标准语言模型（SLM）：自回归方式
2.  受损文本重建（CTR）：对文本中有噪声的部分进行恢复
3.  全文重构（FTR）： 重构整个文本，不管是否有噪声

2.  噪声类型：

1.  掩码（Masking）：文本在不同的级别上mask，可以是token，也可以是实体之类的
2.  替换：不是加 [MASK]，而是用其他单个 token 或多个 token 进行替换
3.  删除：一个或多个 token 从文本中删除
4.  排列：分成不同的片段，重新排列

3.  Prompt 设计（Prompt Engineering）：

1.  手动模板：LAMA数据集（2019）提供了手动创建的完形填空模板，后续还有很多其他的
2.  自动模板学习：又分离散的和连续的 prompt 模板

4.  离散prompt：人类可读的文字模板

1.  prompt mining：从维基百科等大语料文本里找包含输入文本x 和标记 y 的文本，利用本文中间词或依赖路径来制作模板，如 [X] 中间词 [Z]
2.  prompt paraphrasing：用翻译 、同义替换的方式生成
3.  Gradient-based search（[海狸同学：论文阅读：AutoPrompt](https://zhuanlan.zhihu.com/p/432575444)）：用梯度的方法，寻找与梯度方向相同且使梯度下降最快的 token 模板
4.  Promot generation：指定在模板中插入模板标记的位置，为 T5 模型提供解码模板标记的训练样本，最终用 T5 生成模板标记（tokens）
5.  Prompt scoring：使用 LMs 为输入三元组设计了一个模板，行程一个 prompt，而后使用单向 LM 对已填写的 prompt 进行评分，选择 LM 概率最高的 prompt，为每个单独的输入生成自定义模板。

5.  连续 prompt：通过 embedding 方式做 prompts。这样做有两个显然的好处：① 放宽模板词的语言限制。②取消模板由预先训练的LM参数参数化的限制，模板有自己的参数，可以根据下游任务的训练数据进行调整

1.  Prefix Tuning（[海狸同学：论文阅读：Prefix-Tuning](https://zhuanlan.zhihu.com/p/422249625)）：比如自回归语言模型，prefix 先在输入钱加一个前缀矩阵 z=[PREFIX;x;y], encoder-decoder 的就是 [PREFIX;x;PREFIX';y]。Prefix-tuning 通过初始化可训练矩阵 $P_{\theta}$ 来存储 prefix 参数。训练目标和 fine-tuing 相同，但语言模型的参数固定，只迭代 prefix 矩阵的参数，这个参数矩阵可以看做一个 prompt 模板
2.  Tuning Initialized with Discrete Prompts：使用离散prompt搜索方法创建或发现的 prompt 来初始化对连续 prompt 的搜索

6.  Answer 设计：这个 answer 就是 z（good， boring 那个）

1.  答案粒度：有 token 级、multi-token 片段、sentence 三种级别
2.  答案空间z到输出空间 y 间的映射：

1.  手动设计：①受限空间：常用于标签空间有限的任务，如文本分类或实体识别，或多项选择问答系统。② 无约束空间：使用标识映射将答案z直接映射到最终输出y
2.  离散答案搜索：①答案释义：从初始答案空间z开始，用翻译或语义空间来进行扩展。② Prune-then-Search：首先生成多个似是而非答案z的初始修剪答案空间，然后算法在该修剪空间上进一步搜索以选择最终答案集。③ 标签分解：自动将每个关系标签分解为其组成词，并将其用作答案

3.  连续答案搜索

7.  Multi-Prompt：大量研究表明，使用多重提示可以进一步提高提示方法的有效性
