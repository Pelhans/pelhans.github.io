# 论文解读：Voyager: An Open-Ended Embodied Agent with Large Language Models（2023）

> 一句话总结：Voyager 用"自动课程 + 可成长的代码技能库 + 带自我验证的迭代提示"三件套，让 GPT-4 在 Minecraft 里实现无需人类干预的终身学习，证明了"技能库（skill library）"是可复用、可组合、抗遗忘的 agent 记忆范式。

## 1\. 背景与动机

在 LLM agent 早期，主流方法（ReAct、Reflexion、AutoGPT）要么是单轮思维链，要么是带自我反思的单次尝试，本质上都不是"终身学习者"：它们不会在长时间跨度内持续获取、更新、积累并迁移知识。经典 RL/模仿学习在 Minecraft 这类开放式世界里又面临探索难、可解释性差、泛化弱的问题。

Minecraft 的特殊性在于它没有预设终点或固定剧情，是一个"无限可能"的沙盒——这恰好是检验终身学习 agent 的理想试验场。人类玩家能做到三件事：(1) 根据当前技能水平与世界状态提出合适任务（如在沙漠先学采沙而非找铁）；(2) 从环境反馈中打磨技能并把已掌握的存进记忆以便复用；(3) 自驱地持续探索新任务。Voyager 的动机，就是让 LLM agent 具备这三件套能力，而不依赖任何模型参数微调。

## 2\. 核心问题

1.  如何让 agent 在没有人类干预的情况下，持续、开放式地探索一个开放世界？

2.  如何让 agent 把学到的行为"存下来、取出来、组合起来"，从而快速复合能力并缓解灾难性遗忘（catastrophic forgetting）？

3.  如何仅凭黑盒 LLM 的提示与上下文学习，从环境反馈与执行错误中自我改进程序，而不做梯度训练？

## 3\. 方法与架构

Voyager 由三个相互咬合的模块组成，核心创新是用"代码作为动作空间（code as action space）"，而非低级 motor 指令——因为程序天然能表达时间扩展（temporally extended）和可组合（compositional）的行为。

```plain
            ┌─────────────────────────────────────────┐
            │           Automatic Curriculum          │
            │  GPT-4 基于"发现尽可能多样的东西"生成任务  │
            │  （in-context novelty search，最大化探索）│
            └───────────────┬─────────────────────────┘
                            │ 新任务
                            ▼
            ┌─────────────────────────────────────────┐
            │       Skill Library（技能库检索）         │
            │  用任务描述的 embedding 检索 top-5 相关技能 │
            │  简单技能经组合合成复杂技能 → 能力复利增长   │
            └───────────────┬─────────────────────────┘
                            │ 拼装初始程序
                            ▼
            ┌─────────────────────────────────────────┐
            │     Iterative Prompting Mechanism        │
            │  ① 环境反馈（中间状态，如"还缺 7 个铁锭"） │
            │  ② 执行错误（语法/API 报错 → debug）       │
            │  ③ 自我验证（另一 GPT-4 当 critic 判定成败）│
            │  循环最多 4 轮；失败则课程切换到更简单任务   │
            └───────────────┬─────────────────────────┘
                            │ 成功
                            ▼
            新技能以可执行 Python 代码写入 Skill Library（持久化到磁盘）
```

技能库是终身学习机制的核心：每个技能由"技能描述文本的 embedding"索引，未来相似情境可检索复用；复杂技能通过组合更简单的程序不断合成，使能力随时间复利增长，并天然缓解遗忘——因为旧技能始终留在库里，随时可被检索，而不是被覆盖。

## 4\. 关键实验与结论

在 MineDojo（Minecraft）基准上与 ReAct、Reflexion、AutoGPT 对比：

-   **独特物品发现**：160 次提示迭代内 Voyager 发现 **63 个独特物品**，是此前 SOTA 的 **3.3 倍**（AutoGPT 约 15–20，ReAct 约 20，Reflexion 约 5）。

-   **探索范围**：移动距离是基线的 **2.3 倍**，遍历更多样地形。

-   **科技树解锁速度**：解锁木制工具比 AutoGPT **快 15.3 倍**，石制 8.5 倍，铁制 6.4 倍；Voyager 是**唯一**解锁钻石工具的方法。

-   **零样本泛化**：把技能库清空物品后放进全新世界测未见任务，Voyager 显著更快；且技能库作为即插即用工具，甚至能提升 AutoGPT 的表现。

-   **消融**：移除自动课程 → 物品发现 **下降 93%**；移除自我验证 → 性能 **下降 73%**（三种反馈中最关键）；GPT-4 比 GPT-3.5 在代码生成上多出 **5.7 倍**物品。

## 5\. 贡献与创新点

-   首个 LLM 驱动的具身终身学习 agent，完全靠黑盒查询、无需微调。

-   提出"代码即动作 + 技能库 + 自动课程 + 自我验证"的可复用范式，技能可解释、可组合、抗遗忘。

-   把"终身学习能力"从 RL 的梯度世界，搬到了 LLM 上下文学习的世界，是 agent harness 中"持久化技能/工具库"思想的奠基性工作。

## 6\. 局限与争议 / 后续工作

-   依赖 GPT-4 黑盒，无视觉感知；控制开销与延迟高（每步多次 GPT-4 调用）。

-   技能库是扁平的 embedding 检索，缺乏层级化/版本管理；技能质量完全取决于 GPT-4 生成与自我验证，可能积累错误技能。

-   场景局限在 Minecraft，未落地真实机器人。

-   后续：与 AutoGen（arXiv:2308.08155）、MetaGPT（arXiv:2308.00352）、Generative Agents 等将"技能/记忆/角色"思想推广到通用多 agent 框架；以及把技能库演化为更工程的 tool registry / vector memory。

## 7\. 与 Agent Harness 的关系

Voyager 对 harness 工程师最直接的启示是：**"记忆"不应只是对话历史，而应是一个可检索、可组合、可持久化的技能（工具）库。**

1.  **把常用能力沉淀为可检索的程序/工具库**：用 embedding 索引 + top-k 检索，让 agent 在相似任务上复用而非从零生成，避免重复探索与遗忘。

2.  **引入"自我验证/critic"环节**：在把结果写入记忆或交付前，用一个验证器判定成败并给出改进建议，这是 Voyager 消融中最重要的模块（去掉掉 73% 性能）。

3.  **用 novelty-driven 课程驱动探索**：harness 的任务调度器可以基于"已覆盖状态"主动提出新任务，而非被动等待用户指令，从而让 agent 持续成长。
