# 论文解读：Reflexion: Language Agents with Verbal Reinforcement Learning（2023）

> 一句话总结：Reflexion 提出"语言强化学习"——不让模型改权重，而是让 agent 在失败后用自然语言写反思、存入情景记忆，在后续试验中改进决策，从而用极少样本快速学会任务。

## 1\. 背景与动机

传统 RL 需要海量样本与昂贵的模型微调，难以直接用于黑盒 LLM agent。ReAct 类 agent 在长程任务中常重复同样的错误（如误以为已拿起物体）。Reflexion 的动机：能否把"试错—反馈"做成上下文内的语言过程，让 agent 自己总结经验、避免重蹈覆辙？

## 2\. 核心问题

-   不更新权重，仅靠"语言反馈"能否让 agent 从失败中持续学习？

-   哪些反馈信号（标量 / 自然语言、外部 / 自模拟）最有效？

-   反思机制相比"单纯把上次失败轨迹塞回上下文"能带来多少增益？

## 3\. 方法与架构

Reflexion 由三个角色组成：Actor（生成轨迹）、环境/工具的反馈信号、self-reflection 生成器。每一轮：Actor 行动 → 得到结果（成功/失败或评分） → 若失败，根据轨迹+反馈写一段"反思"（定位错误、给出下次启发式） → 存入 episodic memory → 下一轮把反思作为额外上下文重试。循环直到成功或达最大试验数。

```plain
Trial t:
  Actor ──action──► Environment
                       │
                  feedback (scalar / language / self)
                       │
                 Reflection LLM ──"我上次错在X，下次应做Y"──► Episodic Memory
                       │
  Trial t+1: Actor + Memory ──► 改进的行动
```

关键：所有学习都在上下文内完成，模型权重不变；反馈可以是单元测试结果（编程）、外部评价或模型自模拟。

## 4\. 关键实验与结论

基准：ALFWorld、HotPotQA、HumanEval / MBPP（编程）。

-   HumanEval（Python）pass@1：Reflexion 91.0%，超过当时 GPT-4 的 80.1%。

-   ALFWorld：12 次试验后 Reflexion 完成 97% 任务，ReAct 基线约 75%（绝对 +22 个百分点）。

-   HotPotQA：ReAct 设置下准确率从 23% 提升到 43%（+20 点）；仅加 episodic memory 收益有限，明确自我反思再带来 +8 点。

-   消融：自我反思 + 自生成测试缺一不可；MBPP 上因自生成测试误报（false positive）反而略低于 GPT-4。

## 5\. 贡献与创新点

把"强化学习"重定义为"语言空间的反思循环"，无需训练即可赋予黑盒 LLM 试错学习能力；提出可解释的 episodic memory；在决策、推理、编程三类任务统一验证。被视为 agent 自我纠错（self-correction）方向的奠基性工作。

## 6\. 局限与争议 / 后续工作

高度依赖反馈信号质量——自生成测试误报会让 agent 误以为通过而提前停止；反思质量受限于底层 LLM；多轮重试带来延迟与成本。后续工作把反思用于代码 agent（如 SWE-agent）、与树搜索/记忆检索结合（如 Voyager、Generative Agents），并演化出 Reflexion 的多种变体。

## 7\. 与 Agent Harness 的关系

-   在 harness 中实现"失败 → 反思 → 重试"闭环，把反思文本作为可审计的 memory，而非只盲目重试 N 次。

-   必须配套可靠的验证器（测试 / 类型检查 / 外部评分）；对反馈质量差的任务，反思可能有害——要给 false positive 设护栏。

-   把"最大试验次数"与步数预算做成一等配置，防止无限反思循环拖垮系统。
